# dmvs_js Documentation

JavaScript for dmview views - the parser of the scripts a converter
compiles into a view's code, and the compiler that does it.

## Contents

- **[api-reference.md](api-reference.md)** - the API and the syntax tree
- **[compiler.md](compiler.md)** - the compiler: what it compiles, how, and its host

View documentation using `dmf-man`:

```bash
dmf-man dmvs_js          # Main documentation
dmf-man dmvs_js api      # API reference
dmf-man dmvs_js compiler # The compiler
```
